# Info

This is a unedited backup version of the [firmware tool](https://stadia.google.com/controller/index_de.html) for the Stadia controller by Google.

# Usage

1. Open [https://christopherklay.github.io/stadiacontroller/](https://christopherklay.github.io/stadiacontroller/) in Chrome version 108 or later.
2. Follow the instructions on the page.

OR

1. Clone this repository.
2. Open `index.html` in Chrome version 108 or later.
3. Follow the instructions on the page.
