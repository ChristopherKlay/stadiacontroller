# Info

This repo a unedited backup version of the [firmware tool](https://stadia.google.com/controller/index_de.html) for the Stadia controller by Google.

## Note

This repo is **not** open for contributions and/or other requests. It's purely designed to work as a online accesible backup of the original tool and the only changes to files are a disclaimer and the removal of automated language based redirections.
